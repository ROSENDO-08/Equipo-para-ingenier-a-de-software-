Configurar Thonny para ESP32

Lo primero antes de cualquier código

▼

Thonny necesita saber que está hablando con el ESP32 y no con tu computadora.

Pasos:
1. Conecta el ESP32 con el cable USB-C
2. Abre Thonny 4.1.7
3. Ve a Herramientas → Opciones → Intérprete
4. Selecciona MicroPython (ESP32)
5. Puerto: elige el COM que aparezca (Windows: COM3/COM4 · Mac: /dev/cu.usbserial...)
6. Clic en OK

✅ Si todo está bien verás en la parte inferior: MicroPython on ESP32 >>>
⚠️ Si no aparece ningún puerto: prueba otro cable USB. Muchos cables son solo de carga y no transmiten datos.

3

Código: LED parpadeando

El "Hola Mundo" del hardware embebido

▼

Este código enciende y apaga el LED cada segundo. Si funciona, el ESP32 está vivo y tu cableado es correcto.

main.py — Blink LED
from machine import Pin
import time

led = Pin(2, Pin.OUT)   # D2 en el board

print("Data Logger ESP32 — Iniciando...")

while True:
    led.value(1)
    print("LED ON")
    time.sleep(1)
    led.value(0)
    print("LED OFF")
    time.sleep(1)
Lo que debes ver en Thonny:

LED OFF

LED OFF
...
⚠️ ¿El LED no parpadea? Revisa: 1) Patita larga al GPIO, patita corta a GND. 2) Resistencia bien insertada. 3) Cable jumper en D2 exactamente.

5

Agregar alerta visual con LED

El LED se enciende si la temperatura es alta

▼

Ahora combinamos el LED del paso anterior con los datos del sensor. Si la temperatura supera 30°C, el LED se enciende como alerta.

main.py — Data Logger + alerta LED
from machine import Pin
import time, random

led = Pin(2, Pin.OUT)
UMBRAL_TEMP = 30.0   # °C — ajustable

print("=== DATA LOGGER ESP32 CON ALERTAS ===")

lectura = 1
while True:
    temperatura = round(random.uniform(18.0, 38.0), 1)
    humedad     = round(random.uniform(40.0, 80.0), 1)

    if temperatura > UMBRAL_TEMP:
        led.value(1)
        estado = "⚠ ALERTA TEMP ALTA"
    else:
        led.value(0)
        estado = "✓ Normal"

    print(f"[{lectura}] {temperatura}°C | {humedad}% | {estado}")

    lectura += 1
    time.sleep(2)
✅ Si el LED se enciende cuando la temperatura simulada supera 30°C y se apaga cuando baja, la lógica del Data Logger está funcionando.
FASE 4
Servidor web — ver datos en el navegador
6

ESP32 crea su propia red WiFi

Access Point — sin necesidad de router

▼

El ESP32 crea su propia red WiFi. Cualquier celular o laptop que se conecte a esa red puede ver los datos del Data Logger en el navegador.

main.py — Data Logger con servidor web
import network, socket, time, random
from machine import Pin

led = Pin(2, Pin.OUT)
UMBRAL = 30.0

# ── Crear red WiFi ──────────────────────────
ap = network.WLAN(network.AP_IF)
ap.active(True)
ap.config(essid='DataLogger-ESP32', password='datalogger123')
print("Red WiFi creada:", ap.ifconfig()[0])

# ── Función para leer sensor (simulado) ─────
def leer_sensor():
    temp = round(random.uniform(18.0, 38.0), 1)
    hum  = round(random.uniform(40.0, 80.0), 1)
    return temp, hum

# ── Servidor web ────────────────────────────
addr = socket.getaddrinfo('0.0.0.0', 80)[0][-1]
s = socket.socket()
s.bind(addr)
s.listen(1)
print("Servidor escuchando en puerto 80...")

while True:
    cl, addr = s.accept()
    temp, hum = leer_sensor()
    alerta = temp > UMBRAL
    led.value(1 if alerta else 0)
    color = "#ff4444" if alerta else "#00ff88"
    estado = "⚠ TEMP ALTA" if alerta else "✓ Normal"

    html = f"""HTTP/1.1 200 OK\r\nContent-Type: text/html\r\n\r\n
<!DOCTYPE html><html><head>
<meta charset='UTF-8'>
<meta http-equiv='refresh' content='3'>
<title>Data Logger ESP32</title>
<style>
  body{{background:#0d0f14;color:#e8eaf0;font-family:monospace;
       display:flex;flex-direction:column;align-items:center;
       justify-content:center;min-height:100vh;margin:0}}
  h1{{color:#ff6b35;font-size:2rem;margin-bottom:2rem}}
  .card{{background:#161920;border:1px solid #2a2f3d;border-radius:12px;
         padding:2rem 3rem;text-align:center;margin:0.5rem}}
  .val{{font-size:3rem;font-weight:bold;color:{color}}}
  .lbl{{color:#6b7280;font-size:0.9rem;margin-top:0.5rem}}
  .estado{{margin-top:1.5rem;font-size:1.2rem;color:{color}}}
  .sub{{color:#6b7280;font-size:0.75rem;margin-top:1rem}}
</style></head><body>
<h1>📊 Data Logger ESP32</h1>
<div class='card'><div class='val'>{temp} °C</div><div class='lbl'>Temperatura</div></div>
<div class='card'><div class='val'>{hum} %</div><div class='lbl'>Humedad</div></div>
<div class='estado'>{estado}</div>
<div class='sub'>Actualizando cada 3 seg · UAG Ingeniería de Software</div>
</body></html>"""

    cl.send(html)
    cl.close()
📱 Después de correr el código: 1) Conecta tu celular a la red WiFi DataLogger-ESP32 (contraseña: datalogger123). 2) Abre el navegador y entra a 192.168.4.1. 3) Verás el dashboard con temperatura y humedad actualizándose cada 3 segundos.
